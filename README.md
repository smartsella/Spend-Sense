# SpendSense Frontend

A modern personal finance management application that helps users track income, expenses, and spending habits through an intuitive dashboard and analytics system.

## 🚀 Features

- User Authentication (Register & Login)
- Dashboard Overview
- Add Income Transactions
- Add Expense Transactions
- Transaction History Management
- Financial Analytics & Reports
- Responsive User Interface
- Secure API Integration
- Real-Time Data Updates

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- JavaScript (ES6+)
- Tailwind CSS
- Axios
- React Router DOM

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/smartsella/spendsense-frontend.git
```

### Navigate to the Project

```bash
cd spendsense-frontend
```

### Install Dependencies

```bash
npm install
```

### Create Environment Variables

Create a `.env` file in the root directory.

```env
VITE_API_URL=http://localhost:5000
```

For Production:

```env
VITE_API_URL=https://your-backend-url.onrender.com
```

---

## ▶️ Run the Application

### Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
